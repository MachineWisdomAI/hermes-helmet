# Assignments by format

Read this when drafting the plan.

## Documents

- One card per section that a reader would recognize as a unit (for example
  "What shipped", "Risks"). Aim for parts a single writer can finish in one pass.
- Give each writer only its own sources. A section that needs another section's
  facts is a sign the split is wrong; merge them or move the shared fact into
  both source lists.
- Put cross-cutting material (summary, introduction, conclusion) with the editor
  only when it is assembled from the others. Otherwise assign it as its own
  section so it is sourced and reviewed.

## Decks

- Assign slide groups, not single slides: an opening, one group per argument,
  a close. Name the number of slides and the single message of each.
- Every slide states its message in the brief. Speaker notes are part of the
  contribution when the deck uses them.
- The editor owns order, repeated claims and visual consistency across groups.
  Writers deliver the slide text and notes in the requested file format.

## Both

- Name the audience, purpose and voice once in the guidance; every card repeats
  them, so writers do not infer them.
- List sources explicitly. A claim without a source is a question for you, not
  a gap for the writer to fill.
- Keep yourself as coordinator on a profile that no writer and not the editor
  uses. Writers and the editor may share one writing profile: each has its own
  card and session, and the editor receives only the accepted inputs its card
  lists.
